A General Education in Mathematics: The Middle Way

Middle Way Mathematics (MWM) is a curriculum and foundational framework for a general education in mathematics. The curriculum targets all motivated students, providing a clear overview of the nature of modern mathematical thought. It is not designed to prepare students for technical STEM tracks; rather, its goal is to provide a conceptual and formal literacy that enables lifelong, thoughtful engagement with formal descriptions - offered in more sophisticated popular science literature and video lectures - of modern physical theories.

1. Mathematics as a Formal Science

Mathematics is treated as a formal science whose home is a world of supposition. It serves as a bridge linking human intuition with empirical experience—an arena where we ask "What if?", trace deductive consequences, and evaluate how effectively the resulting structures model physical observations, as illustrated.

MWM does not claim to model all of mathematics. It focuses specifically on the mathematics supporting mathematical physics, balancing two design parameters:

  1. What physical theories can be modeled?
  2. At what level of depth can the modeling mathematics be understood?
MWM expresses its concepts formally, embedded in natural language explanations, using single-sorted first-order logic and ZF set theory as its foundational baseline.

2. The Cornerstone Axiom, Ordinals, and Number Trees

MWM operates as an effective model: rather than building foundational set-theoretic proofs from scratch, it asserts established mathematical structures as governing axioms. The cornerstone axiom of MWM is:

(No(ε₀), +, ·) is a totally ordered algebraic field

where:

  • The carrier set No(ε₀) consists of nodes on the 2-successor number tree whose tree depth (birthday) is strictly less than the ordinal ε₀.
  • The total order (≤) and the arithmetic operations (+, ·) are defined recursively with respect to the node's stage of creation, i.e. it's birthday.

Because No(ε₀) is non-Archimedean, standard ε–δ analysis is set aside in favor of a constructive nonstandard analysis. No(ε₀) serves as the ambient field for all arithmetic and continuous modeling.

the ordinals

The class of ordinal numbers play an important role in modern mathematics. The ordinals model the concept of a collection of well ordered elements. Most graduates of a general education still model well ordered elements with perhaps the first mathematical model they encountered: the natural numbers. The ordinals provide a much more extensive model of order. However, like the cornerstone axiom, the ordinals will not be formally modeled; instead they are assumed to be mathematical fact. The natural language description is that the ordinals are the equivalence classes of isomorphic (set,<w) pairs over the universe of sets & their possible well orders, where the von Neumann ordinals are a canonical class of equivalence class instances consistent with ZF axioms.

The finite ordinals coincide with the natural numbers (as defined by finite induction). The ordinal ω is the supremum of the natural numbers, and the ordinal ε0 is greater than ω+1.

number trees

MWM considers numbers to be the elements of sets defined by 2 and 4 successor inductive definitions whose inductive stages are indexed by the ordinals. As the elements of the set in the 2-successor case can be represented by a binary tree, the set is referred to as a number tree. John Conway was the first to describe recursive definitions for a total order among elements (nodes) of a number tree, as well as recursive definitions for adding and multiplying numbers. It is these recursive definitions that are referred to when denoting the totally ordered algebraic field as No(ε0), +, ·).

3. Key number tree number sets

Besides the set No(ε0), we want to define two other number tree sets. Let No(α), where α is an ordinal, denote the set of all number tree nodes whose birthday is less than α; then

  • No(ω)  is the set of all finite ordinals, and
  • No(ω+1) is {the set of all finite ordinals} union {the set of all number tree nodes whose birthday is ω}.
We consider the commutative ring (No(ω), +, ·) where the operations are inherited from No(ε0).  We demonstrate the isomorphism between (No(ω), +, ·) and (𝔻, +, ·) where elements of 𝔻 are dyadic rationals and operations on 𝔻 are those of dyadic arithmetic. 𝔻 becomes the arena of all numeric calculation in MWM. Thus numeric calculation occurs within the context of an Euclidean domain rather than a field.We don't consider any algebraic structure for which No(ω+1) is the carrier set. Instead we only use No(ω+1) as a source for the numbers that can be used in algebraic expressions, as part of a syntactic vocabulary. But we note that these numbers also exist in No(ε0), and so are elements of an algebraic field. We also note that x ∈ ℝ ⇒ x ∈ No(ω+1); however, there is no algebraic structure associated with No(ω+1) with which to compare to the Archimedean field (ℝ, +, ·). And we finally note that No(ω+1) includes elements not in ℝ. In particular No(ω+1) includes non-finite and infinitesimal numbers.

4. The Precision Evaluation Function

To evaluate an algebraic expression E whose number terms belong to No(ω+1), MWM defines a computable truncation map:

eval(E, p)

Given a target precision p ∈ ℕ:

  1. Each number node in E is replaced by its 2-successor tree address truncated to the first p directional choices, yielding an exact element of 𝔻.
  2. Infinitesimal terms are bounded and resolved, reproducing the standard part map (st) of nonstandard analysis.
  3. The expression resolves to an expression whose number terms are dyadic rationals.
