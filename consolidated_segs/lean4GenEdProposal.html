Democratizing Interactive Formal Proof

— A Narrowed-Scope Lean 4 Educational Interface & Multi-Service Grounding Sandbox for General Science Literacy —

NSF IUSE / Sloan Educational Proposal:
Wrapping Lean 4 inside a visual "Tactic Shield" UI and coupling formal logic with symbolic CAS derivations, numeric physical simulations, and a pluggable FS-Widget Sandbox to provide 100% of students zero-friction access to machine-verified formal science.

1. Executive Summary & Vision

Interactive Theorem Provers (ITPs) like Lean 4 represent the pinnacle of verifiable science and formal mathematics. Yet Lean 4’s steep learning curve—steeped in dependent type theory, universe levels, and tactic metaprogramming—erects an insurmountable wall for 99% of general education students. At the same time, conventional STEM education suffers from a false dichotomy: students either manipulate abstract symbols in pure isolation or run ungrounded numerical simulators detached from axiomatic truth.

This proposal presents an integrated educational interface and service architecture that democratizes formal mathematics through three interlocking advances:

  1. A Domain-Restricted "Tactic Shield": Encloses Lean 4 kernel verification in a human-friendly visual harness on middlewaymath.app, insulating students from raw compiler diagnostics.
  2. A 3-Tier Multi-Service Grounding Pipeline: Combines Lean 4 formal certification with Maxima CAS algebraic derivations, dedicated physical bridge simulations, and real-time Formal Statement (FS) inversion calculators.
  3. The MWM FS-Widget Linkage Sandbox: An open-ended visual laboratory allowing learners and educators to wire mathematical propositions directly to dynamic visualizer widgets in arbitrary configurations with real-time formal invariant checking.

2. Key Innovations: The 3-Tier Multi-Service Architecture

  • Tier 3 (Constitutional Foundation in Lean 4): Machine-checked nonstandard calculus (transfinite domains ℝ_ω, ℂ_ω, infinitesimal differentials dx = 1/ω, discrete telescoping FTC, Cauchy contour integration, and unitary quantum dynamics) proven in MiddleWayLean/Scaffold.lean.
  • Tier 2 (Symbolic & CAS Grounding in Maxima): Automated symbolic derivation and polynomial reduction traces (genMaximaCache) that compute intermediate expansions, Taylor stencils, and pairwise edge cancellations, certifying the exact algebraic mechanics of every theorem.
  • Tier 1 (Interactive Ground & Dynamic Inversion): Real-time visual evaluation of discrete transects, bounded predicate searches, dedicated physical bridge simulations (kinematics, work-energy, thermal Laplacian diffusion, complex circulation), and a generic algebraic FS Calculator.
  • Dual Static Cache & Live Server Hybrid: Employs build-time kernel pre-computation (genLeanCache, 51 certified theorem keys) ensuring 100% of static web readers on middlewaymath.app receive instant verification (Q.E.D. ✓ in milliseconds) at zero cloud cost, while seamlessly connecting to live Lean 4 servers during interactive local exploration.
Pedagogical Benefits of Unified Multi-Service Access:
Traditional curricula separate logic, algebra, and physics into disconnected silos. Access to unified formal, symbolic, and numeric services transforms how students build intuition:
  • From Rote Memorization to Multi-Angle Grounding: A student studying free fall acceleration does not merely memorize a(t) = -g. They inspect the Lean 4 proof certifying Jane's 3-point difference stencil, view the Maxima symbolic reduction canceling hyperfinite dust, run the interactive physical simulation of the flight trajectory, and invert the relation in the FS Calculator to solve for required launch velocity or transit time.
  • Elimination of the "Black Box" Syndrome: In conventional simulation software, numbers emerge from hidden numerical code. Under MWM, every slider, trajectory point, and state vector is explicitly grounded in an inspectable, certified Formal Statement.
  • Directional Agility: Rather than being locked into one textbook direction (e.g. calculating velocity from time), the FS Calculator derives all valid algebraic inversion sets (inputs → output) directly from the FS, enabling students to explore inverse problems and parameter sensitivities intuitively.

3. The Frontier Initiative: The MWM FS-Widget Linkage Sandbox

Building upon our field-tested argument cards and calculators, this grant establishes the MWM FS-Widget Linkage Sandbox—a visual canvas where students and educators can freely explore, link, and experiment with mathematical structures:

  • Modular Formal Statement (FS) Nodes: Discrete nodes representing formal mathematical relations (kinematic curvature, conservation of mechanical work, heat diffusion stencils, complex multiplication, order inequalities) exposing typed input and output ports.
  • Composable Interactive Visualizer Widgets: A rich library of visual components (1D/2D coordinate transects, time-scrubbing sliders, velocity phase plots, kinetic energy gauges, thermal contact grids, complex Argand loops).
  • Dynamic Port-Wiring & Role Inversion: Learners wire widget outputs to FS inputs in diverse arrangements (e.g. connecting a thermal diffusion stencil to a boundary temperature slider and plotting the resulting center-slice cooling rate in real time). Switching the target variable automatically reconfigures the algebraic dataflow without custom coding.
  • Real-Time Formal Invariant Guardrails: As students drag sliders or rewire connections, the backend Lean 4 / CAS constraint checker monitors constitutional invariants (e.g., probability norm preservation ∥ψ∥² = 1, non-negative mass, or edge circulation vanishing). If a parameter choice violates an invariant, the sandbox highlights the broken axiom with constructive Socratic hints.
Live, Field-Tested Prototype: Active on middlewaymath.app Today
The feasibility of this approach is already established live across the curriculum:
  • 50+ Integrated Lecture Modules: Vectors, Analysis 1D, Bayesian Inference, Quantum Logic, and STEM Bridges deploy interactive <fsd-ref> elements linking narrative prose to certified Argument Cards.
  • Established Physical Bridge Simulations: Newtonian Free Fall, Work-Energy Conservation, Discrete Heat Diffusion, and Cauchy Complex Multiplication run client-side with zero latency.
  • Generic FS Inversion Engine: The new FS Calculator automatically analyzes Formal Statements, extracts free variables, infers inverted directional sets, and computes verified outputs in real time.
  • Zero Speculative Risk: Reviewers can test the working system today in any standard browser. Grant funds go directly toward developing the visual sandbox canvas, multi-tenant cloud orchestration, open student proof synthesis, and rigorous educational cohort assessment.
Architecture Clarification: Public Static Web Deployment vs. Developer / Research Environment
To ensure sustainable, zero-cost global distribution without requiring expensive ongoing cloud server infrastructure, the platform maintains a clean operational boundary between public static web pages and the local developer/research environment:
  • Public Static Web Readers (middlewaymath.app): General education students and web visitors access pre-computed Lean 4 kernel certifications (51 cached Q.E.D. proofs), full deductive argument structures, and client-side physical bridge simulations directly in any modern browser without configuring compilers or servers.
  • Developer / Researcher Extended Environment: Advanced interactive capabilities—including live interactive Lean 4 kernel compilation (npm run leanServer), automated Maxima CAS derivation pipelines (npm run maximaCache), and the experimental FS Inversion Calculator & Sandbox prototyping harness—operate in the local developer environment (npm run dev or ?dev=true).
  • Open-Source GitHub Project Repository: The entire verified scaffold codebase, Lean 4 kernel source, CAS derivation scripts, and developer tooling are openly hosted and documented on GitHub at:
    https://github.com/jpryan17/hobbyNotes
    Inviting contributing researchers, university instructors, and developers to clone the full stack, run the live verification microservices locally, and author custom formal scaffolds.
