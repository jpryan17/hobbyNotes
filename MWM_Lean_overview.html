middle way mathematics and Lean


Middle way mathematics (MWM) is a hobby level project to develop a curriculum and content for a general education in science for all, not just STEM oriented students. A multilayered description of the current curriculum and it's content is maintained on the web site middlewaymath.app.

Lean 4 is an open-source programming language and interactive theorem prover. Lean supports formal statements that can be both verified, and used for calculation. MWM only uses Lean for verification, and handles calculation - and it's relation to formal statements - internally. 

The aforementioned MWM web site consists of a static page and has no connection to the Lean runtime. The MWM development environment prepares a static page for deployment. This workflow is the primary way in which MWM uses Lean. Additionally a runtime version of the app, running in the browser of the dev machine, has runtime access to Lean, as illustrated by the following diagram.

MWM includes a single Lean source file: the Lean scaffold. MWM HTML text segments include embedded custom elements to describe formal statements. They connect MWM statements to the Lean scaffold.
