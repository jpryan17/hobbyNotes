## 🌟 Overview & Mission

**Mathematics and the Middle Way** is an interactive, constructive textbook and formal science curriculum. It is driven by a single conviction: **our theories of physical reality are among the supreme pinnacles of human culture**.

Standard STEM education constructs the mathematical universe through heavy continuous calculation tools designed for professional engineers—epsilon-delta limit towers, metric topologies, and measure theory. 

This project presents a **Middle Way**—a direct, constructive path through formal logic, discrete number trees (`ℕ_ω, ℝ_ω, ℂ_ω`), and nonstandard analysis that reaches the exact same physical reality with total visual transparency.

---

## 🗺️ Curriculum Architecture

The curriculum unfolds across two complementary and sequential tracks, with the second building directly upon the foundation laid by the first:

### Track 1: General Science Foundation
*A complete, standalone foundational sequence for 100% of students (unburdened by continuous calculus):*
1. **Propositional Logic &amp; TTD:** Truth tables, Boolean connectives, and the interactive Truth Table Demo.
2. **Formal Statements &amp; FSD:** Predicate logic, set tuples, and the Formal Statements Demo on a 32x32 grid.
3. **Numbers &amp; Graph Trees:** Constructing 1D `ℝ_ω` (2-successor) and 2D `ℂ_ω` (4-successor) continua with step size `dx = 1/ω`.
4. **Bayesian Inference &amp; BTD:** Inverse probability, belief updating, and the Bayesian Tree Demo.
5. **Quantum Logic &amp; Inference:** Phase rotations, complex probability amplitudes, and quantum state projections.

### Track 2: Liberal Arts Mathematics &amp; Seminars
*A tertiary extension that depends directly upon Track 1, deepening structural mechanics:*
* **Course 1: Linear Algebra &amp; Vector Spaces:** Emergent group structures, linear transformations, and inner product spaces.
* **Course 2: Analysis 1D:** The infinitesimal microscope, algebraic derivatives, local linearity, and telescoping integration.
* **Course 3: Analysis 2D:** The complex grid `ℂ_ω`, conformal geometry, discrete contour integrals, and continuous quantum evolution.
* **Applied Mini-Seminars:**
  - *Mini-Seminar 1:* The Fourier Duality &amp; Canonically Conjugate Variables (`x ↔ p`, `t ↔ E`)
  - *Mini-Seminar 2:* Standard `ω`-Nodes to Halo Soup (Particles to Matrices &amp; Non-Monotonic Theories)
  - *Mini-Seminar 3:* Holography &amp; Information Boundaries (Edge Cancellations to Area Laws)
  - *Mini-Seminar 4:* Higher-Successor Definitions (`2^k` branching hierarchy: 8 gluons, 16-spinors)
* **Satellite Masterclasses:** *Cosmology as Information*, *The Logic of the Particle Zoo*, and *Quantum Entanglement*.

## 💻 Local Development &amp; Deployment

```bash
# Install dependencies
npm install

# Launch local development server
npm run dev    # (short alias: npm run d)

# Build all 47 segment files and index
npm run build  # (short alias: npm run b)

# Commit and deploy live to middlewaymath.app
npm run deploy # (short alias: npm run p)
```
