formal statements


The subject of formal statements naturally follows the subject of propositional logic. This is because quantified predicates are propositions, and a quantified predicate expression is a propositional expression.

We want to make statements about collections. As our target is basic education, we can comfortably limit ourselves to collections of cardinality easily handled by standard set theory. We adopt the perspective established by axiomatized ZF set theory. As the only type is set, we can use the language of classical single-sorted first order predicate logic.

We assume a universal collection of sets, and denote it with 𝒱𝒱. This collection, on pain of paradox, cannot be a set. But we use it to describe the universal predicate of our adopted set theory: membership, which we denote
  • ∊:𝒱×𝒱→𝔹\in:𝒱\times𝒱\to𝔹  
where 𝔹𝔹 is a binary set whose members are interpreted as Boolean truth values; this is analogous to how standard predicates will be handled. Unlike standard predicates, like (propositional) logical operators, the membership predicate is part of our formal language based on vanilla FOL.

We do not discuss the topic of inference mechanisms; we are only interested in the language, and specifically, simple quantified predicate expressions. The goal is not mastery of the language of FOL It is a concrete means of allowing the student to become familiar with the notion of a formal statement.

set constructors

We assume two basic set constructors
  • product, denoted ×\times
  • and directed pair, denoted →\to 
A product combines sets where, besides bookkeeping, the order of factors is insignificant. The order of sets in a directed pair is relevant. There is a from or domain set, and a to or codomain set. At this basic level, we prohibit (even thinking about) a directed pair from being used as a domain or codomain of any directed pair.

function

A function is
  • a directed pair
  • and a rule that assigns to any member of the domain, a member of the codomain.

For example - given addition is defined for the naturals -

  • ℕ→ℕℕ\toℕ
  • add 2 to any member of the domain

and

  • ℕ×ℕ→ℕℕ\timesℕ\toℕ
  • add the product factors

are functions. A function is often identified by prepending the directed pair with a name [colon]; e.g.

  • add_two: ℕ→ℕℕ\toℕ
might refer to the function that adds 2 to the input.

predicate expression

The same set of logical operators developed for constructing propositional expressions can be used to construct predicate expressions.

quantification

A predicate expression may be quantified.

The goal is to expose the student to experience with simple quantified expressions.
