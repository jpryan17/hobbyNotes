— The Middle Way Mathematics Foundation —

Foundation Proposal Overview:
Automated Agentic Mining of Symbolic Algebra Systems (Maxima) for Machine-Checked Formal Verification in Lean 4.

1. Executive Summary & Vision

Computer Algebra Systems (CAS) such as Maxima encapsulate over half a century of mathematical algorithm design and symbolic identities. However, classical CAS operate as unverified "black boxes" that frequently obscure domain assumptions, parameter boundaries, and branch cut limits.

This proposal outlines a public-private partnership model: an initiative led by The Middle Way Mathematics Foundation partnering with a contracted AI Technology Organization (RFP-selected) to build an autonomous agentic system. The pipeline systematically probes Maxima, extracts atomic symbolic identities, enriches them with semantic metadata, and verifies them as machine-checked theorems in Lean 4.

2. Key Architecture: The Algorithm Identification Scheme

The core technical novelty is an Algorithm Identification Scheme that maps procedural Lisp routines in Maxima to formal semantic signatures:

  • Multi-Agent Maxima Harness: Autonomous LLM-driven loops probe Maxima's Lisp core across calculus, differential equations, and special functions.
  • Algorithm Identification: Classifies the underlying CAS routine (e.g., Risch integration, Gosper summation, matrix reductions), isolates operational boundaries, and tags output with a machine-readable semantic identity code.
  • Boundary Fuzzing: Tests edge cases (e.g., singular points, parameter boundaries a = 0, complex branch cuts) to infer explicit mathematical assumptions required for soundness.
  • Lean 4 Verification: Automatically translates extracted identities into typed Lean 4 ASTs and runs tactic proof verification (`simp`, `ring`, `linarith`).

3. Foundation Governance & Scientific Advisory Board (SAB)

To ensure rigorous technical oversight and feasibility without overburdening foundation executive leadership, the project seats a 3-member Scientific Advisory Board (SAB) comprising experts across three domains:

SAB Specialist Role Domain Responsibility
Lean 4 / Theorem Proving Specialist Oversees AST translation fidelity and Mathlib pull-request readiness.
Computer Algebra System Maintainer Audits Maxima Lisp core integration and boundary condition fuzzing.
Agentic AI Systems Architect Evaluates RFP vendor bids, auditing agent swarm orchestration and infrastructure.
SAB Governance Workflow:
Prior to issuing the technical RFP, the SAB reviews and validates the core semantic foundations (mathematical ontology and precondition schemas) and conducts an overall feasibility assessment. The SAB then evaluates vendor RFP bids, selects the winning tech partner, and audits deliverables at 6-month milestones.
