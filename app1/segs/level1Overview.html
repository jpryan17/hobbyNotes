Constructing the Formal Foundation

Every tower of thought requires an unshakeable foundation. In Level 1: Logic & Number, we construct the formal grammar and foundational number scaffolds that empower all subsequent levels of our curriculum.

Rather than accepting real numbers or logical rules as unexamined postulates from authority, we build from first principles: starting with binary truth values in propositional logic, elevating to quantified predicates over sets and tuples, and growing numbers Day by Day from John Conway's inductive root 0 = { | }.

The Three Pillars of Level 1

1. Propositional Logic: Deductive Certainty

Formal science begins on familiar intuitive ground: the Boolean domain 𝔹 = {0, 1}. A proposition is any statement that evaluates unequivocally to True or False. Using the five standard connectives (¬, ∧, ∨, →, ↔), we evaluate compound claims via systematic truth tables and celebrate the strict monotonicity of deductive proof: once a theorem is proven from premises, discovering new facts cannot overturn it.

  • Interactive Suite: The Truth Table Demo (TTD) enables interactive formula construction, evaluation, and truth table verification.

2. Formal Statements: Predicate Logic & Relational Geometry

Moving beyond atomic variables, we introduce typed domains, sets, tuples, and predicates as functions mapping candidate objects into 𝔹. By visualizing binary predicates on the 2D Boolean Relation Matrix, logic gains geometric spatial clarity.

  • Formal Statement Demo (FSD): Parses quantified first-order predicate structures and syntax trees.
  • Equation Evaluator Demo (EED): Interprets predicate calculations directly via an independent execution engine.
  • Machine Verification: Formal statements are verified with the Lean theorem prover to ensure internal consistency.

3. Numbers & Trees: The Conway Number Generator

With logic established, we construct numbers constructively. Starting from nothing — Conway's root 0 = { | } — numbers are born across inductive Days:

  • Day 0: The empty cut creates 0 = { | }.
  • Finite Days: The integers ℤ and dyadic rationals ℚ_2 populate the branching tree.
  • Transfinite Day ω: The supremum limit ordinal yields infinite numbers (ω) and reciprocal infinitesimals (dx = 1/ω).
  • Continua & Rotors: 2-successor dyadic branching generates the 1D real continuum ℝ_ω, while 4-successor quad-trees generate the 2D complex plane ℂ_ω.
  • Binary Tree Demo (BTD): Renders and traverses the recursive Conway birthday tree interactively.

With deductive certainty, predicate language, and the Conway number tree in hand, we are fully prepared to cross the threshold into Level 2: Space, Direction & Geometry.
