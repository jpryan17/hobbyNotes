What is a Proposition?

“In propositional logic, a proposition is any statement that can be judged to be strictly true or false.”

“Aren’t all statements either true or false?” Jill asked.

“Not necessarily. Questions, commands, paradoxes, and vague opinions don’t have clear truth values. There are even formal logics with multiple truth values. But in propositional logic, we make a fundamental ground rule: every proposition is either True (1) or False (0). There is no middle ground.”

“In many ways, a formal logic is like a game logicians invented to capture a crisp slice of decision making. If you follow the rules, your conclusions will never contradict your assumptions.”

“For example, take these two statements:”

  • It is raining.
  • It is dark.

“We assume circumstances allow each question—Is it raining? Is it dark?—to be answered with a definite yes or no. The logic game doesn't actually care if it's raining outside right now; it only cares that each statement has been assigned a Boolean truth value.”

Naming Propositions: p, q, r, s

“Writing out full English sentences every time is tedious, especially when all we care about is the truth value. So we assign short names to our propositions:”

  • 'It is raining' might be named ℛ
  • 'It is dark' might be named 𝒟

“To keep things uniform and clean across our interactive truth tables, we will standardly use four single-letter proposition names: p, q, r, and s.”

“On this page, these names are interactive! When you click on any highlighted red expression, it opens directly in our Truth Table Demo (TTD).”

For example, clicking on a single bare proposition:

  • p  or  r

shows its basic 2-row truth table: when p is True, the expression is True; when p is False, the expression is False.

The Basic Logical Operators: ¬, ∧, ∨, ↔

“Now, how do we combine simple propositions into richer statements? We use logical operators.”


1. The NOT Operator (¬) — Negation

The not operator (denoted by ¬) reverses a proposition’s truth value. It is a unary operator (it acts on a single proposition):

  • Click ¬ p or ¬ r to inspect the inverted truth table.

2. The AND Operator (∧) — Conjunction

The and operator (denoted by ∧) is True only if both propositions are true, and False otherwise:

  • Click p ∧ q or q ∧ s to inspect the 4-row conjunction table.

3. The OR Operator (∨) — Disjunction

The or operator (denoted by ∨) is True if at least one proposition is true, and False only if both are false:

  • Click p ∨ q or q ∨ s to inspect the disjunction table.

4. The SAME Operator (↔) — Equivalence

The equivalence operator (denoted by ↔) is True if both propositions have the same truth value (both True or both False):

  • Click p ↔ q or q ↔ s to inspect the equivalence table.

Operation Symbol Meaning
Not (Negation) ¬ Inverts truth value (True → False, False → True)
And (Conjunction) ∧ True only when both inputs are True
Or (Disjunction) ∨ True when at least one input is True
Same (Equivalence) ↔ True when inputs match in truth value

Compound Expressions & Tautologies

“Operators can act not only on single propositions, but on entire compound expressions using brackets [ ... ]:”

  • Negating a Conjunction: ¬ [ p ∧ q ]
  • Negating a Disjunction: ¬ [ p ∨ q ]
  • Double Negation: ¬ [ ¬ p ]
  • Mixed Connectives: p ∧ [ q ∨ r ]  and  [ p ∧ q ] ∨ r

“Now look closely at this double negation equivalence statement:”

¬ [ ¬ p ] ↔ p

“Click on it,” Jack instructed. “Look at the outermost column in the truth table. What do you notice?”

“Every single row is True!” Jill observed.

“Exactly. That is what logicians call a tautology. A tautology is a propositional expression that is always true, regardless of the truth values assigned to its component propositions.”

Material Implication: p → q

“One compound expression appears so frequently in science and mathematics that it gets its own special symbol: material implication (→).”

“The statement 'If p then q' (written p → q) is defined as: 'Either p is false, or q is true' (¬p ∨ q).”

“We can verify that this definition is completely sound by checking that the equivalence is a tautology:”

[ ¬ p ∨ q ] ↔ [ p → q ]

“Furthermore, two-way mutual implication is logically identical to equivalence:”

[ [ p → q ] ∧ [ q → p ] ] ↔ [ p ↔ q ]

Algebraic Laws of Logic

“Just like arithmetic has algebraic laws (like a + b = b + a), propositional logic has algebraic properties that can be proved directly with truth table tautologies:”

1. Commutative Laws (Order Doesn't Matter)

  • Conjunction: [ p ∧ q ] ↔ [ q ∧ p ]
  • Disjunction: [ p ∨ q ] ↔ [ q ∨ p ]
  • Equivalence: [ p ↔ q ] ↔ [ q ↔ p ]

2. Associative Laws (Grouping Doesn't Matter)

  • Conjunction: [ [ p ∧ q ] ∧ r ] ↔ [ p ∧ [ q ∧ r ] ]
  • Disjunction: [ [ p ∨ q ] ∨ r ] ↔ [ p ∨ [ q ∨ r ] ]
  • Equivalence: [ [ p ↔ q ] ↔ r ] ↔ [ p ↔ [ q ↔ r ] ]
