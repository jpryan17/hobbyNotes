Coupling Formal Verification with Conversational AI

— A Dual-Layer Architecture for Sound, Hallucination-Free Intelligent Tutoring Systems —

Academic Whitepaper & NSF CHS Proposal:
Combining formal Lean 4 / CAS backends (for 100% sound verification) with conversational LLM frontends (for empathetic, human-level explanation).

1. Abstract & Research Problem

Generative AI tutors excel at natural language explanation, but suffer from mathematical hallucinations. Conversely, Interactive Theorem Provers (Lean 4) guarantee absolute logical validity, but emit dense compiler diagnostics (type mismatch at term h) that alienate students.

We propose a Dual-Layer Architecture: an unyielding formal verification kernel (Lean 4 / Maxima CAS) running at the backend, coupled with a conversational LLM agent at the frontend. The frontend agent inspects the Lean 4 proof state in real time when a student clicks [ Help ], translating formal logic into student-tailored Socratic hints with zero mathematical hallucinations.

2. Dual-Layer Paradigm

  • Layer 1 (The Soundness Anchor): Lean 4 / Maxima kernel running via WebAssembly / WebSocket. Evaluates proof steps with 100% logical rigor.
  • Layer 2 (The Conversational Interpreter): LLM agent frontend that translates raw compiler diagnostics into friendly, Socratic pedagogical hints.
