Introduction: Propositional Logic
Deductive Certainty, Boolean Connectives & The Truth Table Demo (TTD)

1. The Goal: Grounding Formal Science on Familiar Terrain

As outlined in the curriculum introduction, the primary goal of Propositional Logic is to expose the student to the formal sciences on familiar, intuitive ground.

Propositional logic is the foundational game of deductive certainty. It begins with a single core supposition: a proposition is any declarative statement that can be judged definitively as either True (1) or False (0) within the binary Boolean set 𝔹 = {0, 1}. There is no middle ground, vagueness, or ambiguity.

The formal system does not concern itself with empirical weather or physical facts; it cares exclusively about deductive validity ("being right" under assigned premises). Deductive proof is strictly monotonic:

If   Premises ⊢ Conclusion,   then   (Premises ∪ New Fact) ⊢ Conclusion

Once a mathematical theorem is proven from premises, discovering new facts can never overturn the proof.

2. Atomic Variables & The Boolean Connectives

To analyze complex arguments without writing long sentences, we represent atomic propositions with abstract variables: p, q, r, s.

These variables are combined into compound expressions using five standard logical connectives:

Connective Symbol English Reading Truth Condition
Negation ¬ "NOT p" (¬p) Inverts truth value: True if p is False; False if p is True.
Conjunction ∧ "p AND q" (p ∧ q) True only if both p and q are True.
Disjunction ∨ "p OR q" (p ∨ q) True if at least one of p or q is True.
Implication → "IF p THEN q" (p → q) Defined as ¬p ∨ q. False only when p is True and q is False.
Equivalence ↔ "p IF AND ONLY IF q" (p ↔ q) True when p and q share the exact same truth value.

4. Tautologies, Contradictions & Algebraic Laws

Compound expressions exhibit fundamental algebraic properties that can be verified live in TTD by clicking the red links below:

  • Tautology: An expression that evaluates to True under every possible truth assignment. Tautologies express universal logical laws. For example:
    • Law of Excluded Middle: p ∨ ¬ p (every proposition is either True or False).
    • Implication Equivalence: [ ¬ p ∨ q ] ↔ [ p → q ] (material conditional definition).
    • De Morgan's Laws: ¬ [ p ∧ q ] ↔ [ ¬ p ∨ ¬ q ] (distributing negation over conjunction).

  • Contradiction: An expression that evaluates to False under all truth assignments. For example: p ∧ ¬ p (the Law of Non-Contradiction states its negation ¬ [ p ∧ ¬ p ] is a tautology).

  • Contingency: An expression whose truth value depends on the specific inputs (e.g., p ∧ q or p ∨ q).

5. Moving Forward: From Propositions to Predicates

Propositional logic provides the indestructible logical skeleton. However, atomic propositions like p and q cannot describe the internal properties of objects or relationships between numbers. In the next module, Formal Statements, we expand this skeleton into full First-Order Predicate Logic by introducing sets, domain-typed relations, and quantifiers.
