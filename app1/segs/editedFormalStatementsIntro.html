Formal Statements

The subject of formal statements naturally follows the subject of propositional logic. This is because quantified predicates are propositions, and a quantified predicate expression is simply a propositional expression.

We want to make formal statements about collections. Because our target is basic education, we can comfortably limit our scope to collections of a size easily handled by standard set theory.

Specifically, we adopt the perspective established by axiomatized Zermelo-Fraenkel (ZF) set theory. In this system, the only fundamental data type is the set. Because everything is a set, we can express all of our ideas using the clean language of classical, single-sorted first-order predicate logic (FOL).

A Note on Bounded Quantifiers vs. "Sorts":
When we write bounded quantifiers like ∀ x ∈ S , P ( x ) (e.g., "for all numbers x in ℕ"), it may appear as though x is assigned a distinct "sort" or data type. However, in single-sorted FOL, bounded quantification is purely a convenient syntactic shorthand (relativization):

(∀ x ∈ S) P(x)  ≡  ∀ x ( x ∈ S → P(x) )
(∃ x ∈ S) P(x)  ≡  ∃ x ( x ∈ S ∧ P(x) )

The variable x still ranges over the single universal domain of all sets 𝒱, and membership in S is simply a condition evaluated inside our single-sorted logic!

To anchor this, we assume an overarching universal collection of all sets, which we denote as the universal collection 𝒱 𝒱 . To avoid logical paradoxes (like Russell's Paradox), this massive collection itself cannot be classified as a set. However, we use 𝒱 𝒱 to define the single absolute bedrock predicate of our entire system: membership, which we denote as:

∈ : 𝒱 × 𝒱 → 𝔹 \in : 𝒱 \times 𝒱 \to 𝔹

where 𝌄 𝌄 is a binary set whose members are interpreted as Boolean truth values; this is analogous to how standard predicates will be handled.

Unlike standard predicates, like (propositional) logical operators, the membership predicate is part of our formal language based on vanilla FOL. We do not discuss the topic of inference mechanisms; we are only interested in the language, and specifically, simple quantified predicate expressions. The goal is not mastery of the language of FOL. It is a concrete means of allowing the student to become familiar with the notion of a formal statement.

Set Constructors

We assume two basic set constructors:

1. The Product ( × )

A product combines sets where, besides bookkeeping, the order of factors is insignificant.

2. The Directed Pair ( → )

The order of sets in a directed pair is relevant. There is a from or domain set, and a to or codomain set. At this basic level, we prohibit a directed pair from being used as a domain or codomain of any directed pair.

Function

A function is a directed pair and a rule that assigns to any member of the domain, a member of the codomain. For example — given addition is defined for the naturals — ℕ → ℕ ℕ\toℕ (add 2 to any member of the domain) and ℕ × ℕ → ℕ ℕ\timesℕ\toℕ (add the product factors) are functions. A function is often identified by prepending the directed pair with a name; e.g., add_two : ℕ → ℕ \text{add_two}: ℕ\toℕ might refer to the function that adds 2 to the input.

Predicate

A predicate is a function whose codomain is the binary set of Boolean truth values. Thus if 𝒮 𝒮 is any set, any function defined for the directed pair 𝒮 → 𝔹 𝒮\to𝔹 is a predicate. For example, if P : ℕ × ℕ → 𝔹 P: ℕ\timesℕ\to𝔹 (where 𝒮 ≡ ℕ × ℕ 𝒮\equivℕ\timesℕ ) and letting ( x 1 , x 2 ) ∈ ℕ × ℕ (x_1, x_2)\inℕ\timesℕ , we have:

( x 1 , x 2 ) ↦ { true if x 1 < x 2 false if ¬ ( x 1 < x 2 ) (x_1, x_2)\mapsto\begin{cases} \text{true if } x_1<x_2 \\ \text{false if } \not(x_1<x_2) \end{cases}

then P is a predicate.

Predicate Expression and Quantification

The same set of logical operators developed for constructing propositional expressions can be used to construct predicate expressions. A predicate expression may be quantified. The goal is to expose the student to experience with simple quantified expressions.
