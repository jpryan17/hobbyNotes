Lecture 2: The Semantics of the Algebra of Sets

To define the algebra of sets for a set 𝒮𝒮, we first define the powerset, denoted 𝒫(𝒮)𝒫(𝒮), which is the set of all possible subsets of 𝒮𝒮.

Then for a base set 𝒮𝒮, its algebra of sets is the algebraic system:

(𝒫(𝒮),⋃,⋂,−)(𝒫(𝒮), ⋃, ⋂, ^-)

Boolean logic will be used to define the operations. You remember Boolean logic—those and(s), or(s), and not(s) you used when building propositional expressions—right?

1. Quantifier Domain Types & The Membership Predicate

In our formal statement language, quantifiers are explicitly bound to their domain types:

  • x:𝒮x : 𝒮 indicates that xx is an individual element of the base universe 𝒮𝒮 (x∊𝒮x ∈ 𝒮).
  • A:𝒫(𝒮)A : 𝒫(𝒮) (or y:𝒫(𝒮)y : 𝒫(𝒮)) indicates that AA is a subset of 𝒮𝒮 (A⊆𝒮A ⊆ 𝒮).

The universal membership predicate is defined as the typed function:

∊:𝒮×𝒫(𝒮)→𝔹∈ : 𝒮 × 𝒫(𝒮) → 𝔹

where for any element x:𝒮x : 𝒮 and subset y:𝒫(𝒮)y : 𝒫(𝒮), the atomic statement x∊yx ∈ y has the direct semantics:

“xx is a member of yy”

evaluating to true\text{true} if xx belongs to the subset yy, and false\text{false} otherwise.

For example, combining a typed existential quantifier with the membership predicate yields the formal statement:

∃x:𝒮[x∊y](where y:𝒫(𝒮))∃x:𝒮 [ x ∈ y ] \quad (\text{where } y : 𝒫(𝒮))

which has the direct semantics: “There is an x∊𝒮x ∈ 𝒮 such that xx is a member of yy” (formally asserting that the subset yy is non-empty).

2. Defining the Operations via Formal Statements

Each operation in the algebra of sets directly reflects a Boolean logical connective:

  • Union (⋃:𝒫(𝒮)×𝒫(𝒮)→𝒫(𝒮)⋃ : 𝒫(𝒮) × 𝒫(𝒮) → 𝒫(𝒮)):
    For any two subsets A,B∊𝒫(𝒮)A, B ∈ 𝒫(𝒮), the union A⋃BA ⋃ B is defined by:
    ∀A:𝒫(𝒮)∀B:𝒫(𝒮)∀x:𝒮[x∊(A⋃B)⇔(x∊A∨x∊B)]∀A:𝒫(𝒮) ∀B:𝒫(𝒮) ∀x:𝒮 [ x ∈ (A ⋃ B) ⇔ (x ∈ A ∨ x ∈ B) ]

  • Intersection (⋂:𝒫(𝒮)×𝒫(𝒮)→𝒫(𝒮)⋂ : 𝒫(𝒮) × 𝒫(𝒮) → 𝒫(𝒮)):
    For any two subsets A,B∊𝒫(𝒮)A, B ∈ 𝒫(𝒮), the intersection A⋂BA ⋂ B is defined by:
    ∀A:𝒫(𝒮)∀B:𝒫(𝒮)∀x:𝒮[x∊(A⋂B)⇔(x∊A∧x∊B)]∀A:𝒫(𝒮) ∀B:𝒫(𝒮) ∀x:𝒮 [ x ∈ (A ⋂ B) ⇔ (x ∈ A ∧ x ∈ B) ]

  • Relative Complement (−:𝒫(𝒮)→𝒫(𝒮)^- : 𝒫(𝒮) → 𝒫(𝒮)):
    For any subset A∊𝒫(𝒮)A ∈ 𝒫(𝒮), its complement A−A^- relative to universe 𝒮𝒮 is defined by:
    ∀A:𝒫(𝒮)∀x:𝒮[x∊A−⇔¬(x∊A)]∀A:𝒫(𝒮) ∀x:𝒮 [ x ∈ A^- ⇔ ¬(x ∈ A) ]

  • Subset Relation (⊆⊆) & Extensional Equality (==):
    ∀A:𝒫(𝒮)∀B:𝒫(𝒮)[A⊆B⇔∀x:𝒮[x∊A⇒x∊B]]∀A:𝒫(𝒮) ∀B:𝒫(𝒮) [ A ⊆ B ⇔ ∀x:𝒮 [ x ∈ A ⇒ x ∈ B ] ]
    ∀A:𝒫(𝒮)∀B:𝒫(𝒮)[A=B⇔(A⊆B∧B⊆A)]∀A:𝒫(𝒮) ∀B:𝒫(𝒮) [ A = B ⇔ (A ⊆ B ∧ B ⊆ A) ]
