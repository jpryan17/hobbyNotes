["Jill."]

Well, Jill, you just used a clever bit of logic, and I stand corrected. I'm not going to talk about logic. I'm going to talk about a formal logic; specifically, I am going to talk about propositional logic. And a formal logic, like propositional logic, cares more about being right than being logical; it just doesn't want to be wrong. That's why its always supposing. And it supposes a lot of things.

And it begins by supposing a proposition is a statement that can be judged to be true or false.

["Aren't all statements either true or false?"]

Well Jill, I don't know, but I think maybe not. There are formal logics where you do not suppose all statements are either true or false, since some logicians think this may be relevant in some cases; but whatever is 'logically correct', propositional logic supposes that a proposition can always be judged as either true or false. There is no middle ground.

In many ways, a formal logic is like a game logicians invent to imitate a small slice of what we might call logical decision making. So if you play the games by the rules, and the game imitates logical thinking, you're thinking logically when you play the game, since you can't be wrong.

But to always be right, you have to suppose a lot of things, and you have to not care about a lot of things. For example here are two statements.
  • It is raining.
  • It is dark.

We assume circumstances are such that each question

  • Is it raining?
  • Is it dark?

can be answered with a yes or no. That is, we assume the two statements are propositions. But the game doesn't really care if it is raining or if it is dark; it only cares the proposition has been assigned a truth value: it supposes these  propositions have been assigned these truth values; it does not suppose the truth values assigned are accurate. This is not a judgment propositional logic makes, since it could be wrong.

Propositional logic provides rules for combining propositions and constructing propositional expressions.

Its a pain to write out the full statement every time you want to refer to a proposition, especially since the only thing you care about is whether it is true or false. So we name propositions, in order to refer to them more easily. For example, we might use names like

  •  'It is raining" is named ℛℛ 
  • "It is dark" is  named 𝒟𝒟
The names don't matter much. Short is good. In fact, we are not in first grade anymore. We can think of any four propositions we want; but so we are all on the same page, we will all name the four propositions we are thinking about as pp, qq, rr and ss. On this page, these names are rather magical. When you use them to construct propositional expressions, and color them rusty red, when you click on them, it brings you to the truth table for the propositional expression.

The truth table for 𝑝 (or 𝑟) shows that a proposition is a propositional expression, but a very boring one. The value of the propositional expression is the value of the proposition.

A slightly less boring propositional expression can be constructed by using the not operator, Like all operators, the not operator will be assigned a symbol; the not operator is denoted by the ¬\not symbol. The not operator reverses a proposition's truth value, e.g. consider the expressions ¬ 𝑝 or ¬ 𝑟, etc.

The not operator is a bit of an exception. It constructs a propositional expression from a single proposition. All other operators construct a propositional expression from two propositions.

The propositional expression constructed from the and operator, denoted by the ∧∧ symbol, is true if both propositions are true, and false if either proposition is false. For example consider the propositional expressions 𝑝 ∧ 𝑞 or 𝑞 ∧ 𝑠, etc.

The propositional expression constructed from the or operator, denoted by the ∨∨ symbol, is true if either propositions is true, and false if both propositions are false. For example consider the propositional expressions 𝑝 ∨ 𝑞 or 𝑞 ∨ 𝑠, etc.

The propositional expression constructed from the same operator, denoted by the ↔↔ symbol, is true if both propositions have the same truth value, and is false if the propositions have different truth values. For example consider the propositional expressions 𝑝  ↔  𝑞 or 𝑞  ↔  𝑠, etc.

The not operator can not only negate (i.e. reverse) a proposition, it can reverse a propositional expression. Consider some examples
  • ¬ [ 𝑝 ∧ 𝑞 ] 
  • ¬ [ 𝑝 ∨ 𝑞 ] 
  • ¬ [ 𝑝  ↔  𝑞 ] 
  • ¬ [ ¬ 𝑝 ] 

The other operators can not only combine two proposition, they can combine two propositional expressions, for example

  • 𝑝 ∧ [ 𝑞 ∨ 𝑟 ] 
  • [ 𝑝 ∧ 𝑞 ] ∨ 𝑟 
  • ¬ 𝑝 ∨ 𝑞 
  • ¬ [ ¬ 𝑝 ]  ↔  𝑝
The last propositional expression listed is what is called a tautology. Now that's a word that might impress your parents. When they ask you what you learned about in school, when you casually say, 'not much, just about, you know, logical tautologies', they may be so impressed or flummoxed they might forget to ask you if you did your homework.

[a few laughs]

And now you know a tautology is just a fancy word for a propositional expression that is always true, no matter the truth value of any proposition in the expression.

The third propositional expression listed, ¬p∨q\notp∨q, is used so often it is written as p→qp\toq. The truth table recognizes this definition, and so
  • [ ¬ 𝑝 ∨ 𝑞 ]  ↔  [ 𝑝 → 𝑞 ] 
is a tautology. This operation is called implication, and is denoted by the →\to symbol. We note
  • [ [ 𝑝 → 𝑞 ] ∧ [ 𝑞 → 𝑝 ] ]  ↔  [ 𝑝  ↔  𝑞 ] 

is a tautology.

Tautologies can be use to prove so called properties of logical operations. For example, the and operation ∧∧, the or operation ∨∨, and the same operation ↔↔ are commutative. This means the order of the two propositions does not matter, as the following tautologies show:

  • [ 𝑝 ∧ 𝑞 ]  ↔  [ 𝑞 ∧ 𝑝 ]
  • [ 𝑝 ∨ 𝑞 ]  ↔  [ 𝑞 ∨ 𝑝 ]   
  • [ 𝑝  ↔  𝑞 ]  ↔  [ 𝑞  ↔  𝑝 ] 
Tautologies also show these three operations are also associative, as shown by:
  • [ [ 𝑝 ∧ 𝑞 ] ∧ 𝑟 ]  ↔  [ 𝑝 ∧ [ 𝑞 ∧ 𝑟 ] ] 
  • [ [ 𝑝 ∨ 𝑞 ] ∨ 𝑟 ]  ↔  [ 𝑝 ∨ [ 𝑞 ∨ 𝑟 ] ] 
  • [ [ 𝑝  ↔  𝑞 ]  ↔  𝑟 ]  ↔  [ 𝑝  ↔  [ 𝑞  ↔  𝑟 ] ] 

Well this is all okay, but what is it good for you might ask.

["Yes we might." Some smiles.]

Well for one thing you just learned Boolean logic. Slip that into your dinner conversation and your parents won't dare ask about homework for a week.

[lighter laughs; jokes get old.]

Of course, you're not experts yet. Some experts use Boolean logic to find the truth values of propositional expressions constructed from millions of propositions. We'd need a pretty big truth table to handle that.

But we are learning propositional logic for a very specific reason: a propositional expression provides the skeletal structure of a formal statement, and formal statements are important in science.
